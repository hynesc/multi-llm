# First GitHub push

This folder is a standalone Git repository with committed public source and setup documentation on `main`.
Its `origin` is configured as `git@github.com:hynesc/multi-llm.git`.

1. Create an empty GitHub repository named **multi-llm** under **hynesc**. Leave the options to add a README, license, and gitignore unchecked because this repository already has its initial commit.
2. From this directory, push:

   ```bash
   git push -u origin main
   ```

The portfolio already points to `https://github.com/hynesc/multi-llm` and its source files on `main`. These links become available after the repository is created and pushed. If you choose another repository name, update `origin`, the project URLs in `pyproject.toml`, and the portfolio links together.

The repository uses a local Git author setting with a GitHub noreply address. No private configuration or previous source history is included.
